# task 01 — Integer arithmetic (BN)

Layer 0. Dependencies: none. Base block for RSA, EC, DH.

## Goal

Implement arbitrary-precision integers (big number) in pure Pascal:
representation, arithmetic, comparison, modular arithmetic, exponentiation,
modular inverse. This is the foundation for all asymmetric algorithms.

## File

`src/tls.bn.pas`

## What to implement

Type `TBN` (integer ≥ 0, arbitrary length):
- Representation: array of 32- or 64-bit words (little-endian by words),
  normalization (no leading zero words).
- Constructors: from `QWord`, from byte array (big/little-endian), from string
  (dec/hex), from `TBytes`.
- Basic arithmetic: `Add`, `Sub`, `Mul` (schoolbook/Karatsuba), `Div`
  (division with remainder), `Neg`/sign (if negatives are needed — for
  modular normalization).
- Comparison: `Compare`, `Equal`, `IsZero`, `BitLength`, `BitAt`.
- Bitwise: `ShiftLeft`, `ShiftRight`, `And`, `Or`, `Xor`, `Not`.
- Modular arithmetic: `Mod`, `ModAdd`, `ModSub`, `ModMul`, `ModPow`
  (binary exponentiation), `ModInverse` (extended Euclidean algorithm).
- Utilities: `ToBytes` (both orders), `ToHex`, `ToString`, `Clone`.
- Random: `RandomBits(n, rng)` — via CSPRNG (task 02).

## Acceptance criteria

- `Mul`, `Div`, `Mod`, `ModPow`, `ModInverse` are correct on numbers up to
  several hundred bits (verified against `bc`/`openssl` or Python).
- `ModInverse(a, m) * a ≡ 1 (mod m)` for prime `m`.
- `ModPow` matches Python's `pow(a, e, m)` on random data.
- Byte ↔ number conversion is reversible (both orders).
- Tests — `tests/test_bn.pas` (fpcunit).

## Tests

- Known vectors: `2^128`, product of large numbers, `ModPow`
  (e.g. `3^413 mod 97`), `ModInverse` on primes.
- Random: generate pairs of numbers, verify `a*b = q*a + r`,
  `ModInverse` on random primes.
- Performance: `ModPow` 2048-bit — acceptable time (seconds, not minutes).

## OpenSSL references

- `crypto/bn/bn_mul.c` (multiplication), `crypto/bn/bn_div.c` (division),
  `crypto/bn/bn_mod.c` (modular), `crypto/bn/bn_exp.c` (ModPow),
  `crypto/bn/bn_mod.c`/`bn_gcd.c` (ModInverse/Euclidean), `crypto/bn/bn_conv.c`
  (conversion), `crypto/bn/bn_rand.c` (random).
