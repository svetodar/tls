# task 10 — X.509 (certificate parsing)

Layer 2. Dependencies: 09 (ASN.1).

## Goal

Parse an X.509 v3 certificate into a structured object: subject, issuer,
validity dates, public key, extensions (SAN, basic constraints, key usage,
extended key usage, AIA).

## File

`src/tls.x509.pas`

## What to implement

- `TX509Cert`:
  - `Version`, `SerialNumber` (`TBN`).
  - `Issuer`, `Subject` — as `TName` (list of RDNs: OID + value).
  - `NotBefore`, `NotAfter` (time).
  - `SignatureAlgorithm` (OID), `Signature` (bytes).
  - `TBSCertificate` (raw DER bytes of the signed part — for signature
    verification).
  - `SubjectPublicKeyInfo` → key type (RSA/EC/DH) + DER of the public key.
  - `Extensions`: `SubjectAltName` (DNS/IP), `BasicConstraints`
    (CA:TRUE/FALSE, pathlen), `KeyUsage`, `ExtendedKeyUsage`,
    `AuthorityKeyIdentifier`, `SubjectKeyIdentifier`.
- `ParseCertificate(der): TX509Cert`.
- Access to the public key in a form convenient for task 06/07
  (RSA `N`,`E` / EC point + curve).

## Acceptance criteria

- Parses real certificates (root CAs, server certificates) without errors.
- Extracts SAN (DNS names), validity dates, CA flag, public key type.
- `TBS` bytes allow signature verification (task 11).
- Tests — `tests/test_x509.pas` (on real DER certificates).
