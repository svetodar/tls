# task 08 — DH (finite fields, DHE)

Layer 1. Dependencies: 01 (BN), 02 (CSPRNG), 03 (SHA-2). Priority lower than
EC (DHE is less common than ECDHE).

## Goal

Implement Diffie–Hellman in finite fields for DHE key exchange in TLS 1.2
(DHE-RSA / DHE-ECDSA). The client generates an ephemeral key and computes the shared
secret.

## File

`src/tls.dh.pas`

## What to implement

- `TDHKey`: `P` (prime modulus), `G` (generator), (opt.) `priv`, `pub`.
- `Generate(priv)` → `pub = G^priv mod P`.
- `ComputeSecret(peerPub)` → `peerPub^priv mod P` (shared secret).
- Built-in RFC 3526 groups (2048, 3072 bits) — `P`, `G` as constants.
- Validation of `peerPub` (in range [2, P-2], not divisible by cofactors — basic).

## Acceptance criteria

- `ComputeSecret` is symmetric (both ends obtain the same secret).
- Match with test vectors (RFC 5114 / RFC 3526).
- Tests — `tests/test_dh.pas`.
