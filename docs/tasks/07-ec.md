# task 07 — EC (P-256, P-384)

Layer 1. Dependencies: 01 (BN), 02 (CSPRNG), 03 (SHA-2).

## Goal

Implement NIST P-256 and P-384 elliptic curves: point operations,
ECDHE (key exchange), ECDSA (certificate signature verification). This is the primary
mechanism of modern TLS (ECDHE + ECDSA/RSA).

## File

`src/tls.ec.pas`

## What to implement

- `TECPoint` (X, Y as `TBN`, point at infinity), `TECCurve` (parameters
  p, a, b, G, n, h).
- P-256 and P-384 parameters (built-in constants).
- Point operations: `Add`, `Double`, `ScalarMul` (double-and-add /
  Montgomery), `Neg`, `IsOnCurve`, `Equal`.
- **ECDHE**: `ECDH(priv, peerPub) → sharedPoint` (X coordinate = shared secret).
- **ECDSA**:
  - `Verify(pub, hash, r, s)` — signature verification.
  - `Sign(priv, hash)` — for tests (k — via CSPRNG, RFC 6979 optional).
- Point formats: uncompressed (0x04||X||Y), compressed (optional) — DER/DER-
  SubjectPublicKeyInfo (with task 09/10).
- `GenerateKey(curve)` — ephemeral key (mandatory for the client).

## Acceptance criteria

- `ScalarMul` matches component-wise addition on small multipliers.
- ECDH: both ends obtain the same shared secret (RFC 6090 test vector).
- ECDSA `Verify` accepts a correct signature, rejects a modified one.
- Match with NIST / RFC 6090 / SEC 1 test vectors.
- Tests — `tests/test_ec.pas`.
