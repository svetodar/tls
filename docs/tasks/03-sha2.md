# task 03 — SHA-256/384/512 + HMAC

Layer 0. Dependencies: none (HMAC depends on SHA-2 in the same file/unit).

## Goal

Implement the hash functions SHA-256, SHA-384, SHA-512, and HMAC. They are used in
TLS-PRF, signatures (ECDSA/RSA), key derivation, integrity headers.

## File

`src/tls.sha2.pas` (HMAC can be in the same unit or `tls.hmac.pas`)

## What to implement

- `TSHA256`, `TSHA512` (SHA-384 is the same 512 with a different IV and truncation):
  - incremental `Update(data, len)`, `Final(out digest)`,
  - one-shot `Hash(data): TBytes`.
  - SHA-256: 32-bit words; SHA-512: 64-bit words (`QWord`).
- Digest length: 32 (256), 48 (384), 64 (512) bytes.
- `THMAC(key, data, hashKind): TBytes` — standard HMAC (RFC 2104).
- Utility: hex representation of the digest.

## Acceptance criteria

- SHA-256/384/512 produce exact values on the standard FIPS 180-4 vectors
  (empty string, "abc", long strings).
- HMAC-SHA256 matches the RFC 4231 vectors.
- Incremental == one-shot on arbitrary chunks.
- Tests — `tests/test_sha2.pas`.

## OpenSSL references

- `crypto/sha/sha256.c`, `crypto/sha/sha512.c`, `crypto/hmac/hmac.c`.
