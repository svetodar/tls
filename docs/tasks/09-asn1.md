# task 09 — ASN.1 / DER

Layer 2. Dependencies: none (pure byte parser).

## Goal

Implement a parser (and, if needed, a serializer) for ASN.1 DER encoding —
the foundation for X.509 certificates, keys, OIDs, names.

## File

`src/tls.asn1.pas`

## What to implement

- `TASN1Node`: type (tag), length, content (for constructed types — a list
  of children), for primitives — bytes.
- **DER parser**: `ParseDER(buf): TASN1Node` — recursive parsing
  (tag, length in short/long form, content). Handling of
  context-specific/universal tags, `[n] EXPLICIT/IMPLICIT`.
- Types: INTEGER, BIT STRING, OCTET STRING, NULL, SEQUENCE, SET,
  OBJECT IDENTIFIER, UTF8String, PrintableString, IA5String,
  UTCTime, GeneralizedTime, BOOLEAN.
- Helpers: `ReadInteger` (→ `TBN`), `ReadOID` (→ string "1.2.840..."),
  `ReadTime` (→ Unix time / TDateTime), `FindByTag`, `FindByOID`.
- (Optional) **DER serializer** — for tests/generation.

## Acceptance criteria

- Correctly parses real DER structures (certificates, keys from
  task 10). Does not crash on nested SEQUENCE/SET, long lengths.
- INTEGER → `TBN` is correct (including leading zero byte for sign).
- OID is decoded into a canonical string.
- Tests — `tests/test_asn1.pas` (on real DER samples).

## OpenSSL references

- `crypto/asn1/tasn_dec.c` (decoding), `crypto/asn1/tasn_enc.c`
  (encoding), `crypto/asn1/a_int.c` (INTEGER), `crypto/asn1/a_objid.c`
  (OID), `crypto/asn1/a_time.c` (time), `crypto/asn1/a_str.c` (strings).
