# task 16 — End-to-end tests (real HTTP over TLS)

Status: done (covered by tests/test_tlssocket.pas and test_tls12_e2e.pas;
the network-required test runs only with `TLS_TEST_NETWORK=1`).

Layer 4. Dependencies: 14, 15 (integration).

## Goal

Verify the whole stack (TLS + a minimal HTTP exchange) against a local TLS
server and, optionally, against real HTTPS endpoints. Final validation that a
client built on the library works without system OpenSSL.

## Files

- `tests/test_e2e_https.pas` (or an extension of the existing E2E tests).
- A local test TLS server (mock): `openssl s_server`/`stunnel` with a test
  certificate as an external reference.

## What to implement

- **Local TLS server (mock)**:
  - Option A: bring up `openssl s_server`/`stunnel` with a test certificate
    (external reference).
  - Option B: a minimal TLS server built on the library (for a fully
    autonomous test without OpenSSL).
- **Tests**:
  - HTTPS GET/POST to the local TLS server → correct response.
  - Verification: trusted test CA → OK; self-signed without CA → rejection
    (plus a "do not verify" mode used by the test only).
  - Streaming over TLS: body chunks are delivered correctly.
  - (Optional, if network is available) HTTPS to a real public endpoint
    (e.g. `https://example.com`) — marked "network required" and skipped
    offline.
- Integration into `make test`: offline tests always run, network tests only
  by an explicit flag.

## Acceptance criteria

- HTTP over TLS to the local server (non-streaming and streaming) passes.
- Certificate verification works (OK / rejection).
- `make test` is green offline (network tests optional).
- Proof: the full path works without system OpenSSL.
